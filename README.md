# Vanilla JS Workspace with Go & IndexedDB

Высокопроизводительное Offline-First веб-приложение для управления рабочим пространством (Workspace), построенное на чистых принципах **ООП (SOLID)** без использования тяжелых фронтенд-фреймворков. 

Проект использует браузерную базу данных **IndexedDB** для автономной работы и компактный сервер на **Go (Golang)** для автоматической синхронизации данных с операционной системой.

## 🚀 Основные возможности

- **Offline-First архитектура**: Данные мгновенно сохраняются локально в IndexedDB и бережно улетают на бэкенд с помощью паттерна **Debounce (задержка)**, предотвращая лишнюю нагрузку на диск.
- **Динамические Справочники**: Конструктор интерактивных таблиц с поддержкой кастомных типов полей (Текст, Числа, Чекбоксы, JSON с автоисправлением синтаксиса и ZIP-архивы).
- **Системные часовые пояса**: Интеграция с базой данных `tzdata` на Ubuntu (Go API) для динамического пересчета международного UTC Timestamp в локальное время выбранного географического региона.
- **Иерархические Проекты**: Рекурсивный ООП-компонент для ведения древовидных списков задач и подзадач любой вложенности.
- **Модульный фронтенд**: Разделение ответственности (Single Responsibility) — каждая сущность управляется изолированными фабриками данных и холста (Canvas).
- **Портативный бэкенд**: Использование встроенного механизма `go:embed`, позволяющего скомпилировать весь сервер и фронтенд в один автономный бинарный файл.

## 📁 Структура проекта

```text
├── main.go               # Многопоточный веб-сервер на Go (API + статика)
├── backup_db.json        # Локальный файл синхронизации базы данных
└── static/               # Изолированный фронтенд-слой
    ├── index.html        # Валидный HTML5 каркас приложения
    ├── css/
    │   └── style.css     # Кастомные стили и анимации индикатора облака
    └── js/
        ├── app.js        # Главный оркестратор приложения и Debounce
        ├── db.js         # Обертка над IndexedDB (Менеджер и Репозиторий)
        └── components/   # Модульные компоненты правого Canvas
            ├── BaseCanvasComponent.js
            ├── NoteCanvasComponent.js
            ├── ProjectCanvasComponent.js
            ├── DirectoryCanvasComponent.js
            └── CanvasUIFactory.js
```

## 🛠️ Запуск приложения

1. Убедитесь, что у вас установлен **Go** версии 1.16 или выше.
2. Склонируйте репозиторий и перейдите в корневую папку.
3. Запустите сервер:
   ```bash
   go run main.go
   ```
4. Откройте в браузере: `http://localhost:8080`

## 🧱 Архитектурные паттерны
- **Strategy / Factory Method**: Абстрактные рендереры полей в `FieldRegistry.js`.
- **Repository**: Инкапсуляция асинхронных транзакций базы данных внутри `EntityRepository`.
- **Service Locator / Registry**: Динамическая сборка интерфейсов холста в зависимости от типа выбранной сущности.
